ربط برنامج أهالي المسيب بـ Supabase
====================================

1) أنشئ مشروعاً جديداً في Supabase.
2) افتح SQL Editor ثم New query.
3) افتح ملف SUPABASE_SETUP.sql الموجود هنا، انسخ محتواه كاملاً، والصقه ثم Run.
4) من لوحة Supabase افتح Connect أو Settings > API Keys وخذ:
   - Project URL
   - Publishable Key (sb_publishable_...)
   لا تستخدم Secret key أو service_role داخل البرنامج.
5) افتح تطبيق أهالي المسيب > الإعدادات والنسخ > المزامنة السحابية — Supabase.
6) ألصق Project URL و Publishable Key.
7) اكتب بريدك وكلمة مرور واختر إنشاء حساب لأول مرة. إذا طلب Supabase تأكيد البريد، أكد الرسالة ثم سجل الدخول.
8) اضغط مزامنة الآن.
9) على الهاتف أو الحاسوب الثاني: ثبّت نفس PWA، أدخل نفس Project URL وPublishable Key وسجل بنفس البريد وكلمة المرور. ستظهر نفس البيانات بعد المزامنة.

مهم:
- البيانات تبقى محفوظة محلياً أيضاً، لذلك التطبيق يستمر بالعمل عند انقطاع الإنترنت.
- عند رجوع الإنترنت تتم محاولة المزامنة تلقائياً، ويمكن دائماً استخدام زر مزامنة الآن.
- هذه النسخة تزامن قاعدة البرنامج كاملة كما هي. إذا أصبحت صور المستمسكات كثيرة جداً، الأفضل في مرحلة لاحقة نقل الصور إلى Supabase Storage لتقليل حجم المزامنة.
